# Student Database — Python & SQLite

A simple student database management project built with Python and SQLite.

## Features

- Create a students table
- Insert student records
- Retrieve all student records
- Update student courses
- Delete student records
- Display student information in the console

## Technologies

- Python
- SQLite3

## How to Run

1. Clone this repository.
2. Make sure Python is installed.
3. Run the following command:

```bash
python Student-Management-System.py
```

The SQLite database will be created automatically.

## Purpose

This project was created for learning Python and understanding basic SQL operations (CRUD).
